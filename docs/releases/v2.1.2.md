# Birak v2.1.2

A patch release on top of [v2.1.1](v2.1.1.md).

## Changes

- SFTP answers a failed operation with a generic "operation failed" status
  instead of the operating system's error text, which named absolute paths on
  the server — the location of `sync_dir` and of the file concerned. The details
  are logged at debug level. The status codes clients act on are unchanged.

## Upgrade from v2.1.1

Replication remains on protocol 4 and the metadata schema is unchanged; nodes
on v2.1.x interoperate. Replace the image and restart node by node. Coming from
v2.0.x, follow the [v2.1.0 upgrade notes](v2.1.0.md#upgrade-from-v204) first.

## Validation

The tag workflow runs the full Linux race and ENOSPC suite, the Windows build,
source and binary vulnerability scans, and the four-node Docker fault and TLS
read acceptance before publishing images.

## Images

Images are published for `linux/amd64` and `linux/arm64`:

```sh
docker pull solkin/birak:2.1.2
```

Version aliases: `2.1`, `2` and `latest`.
