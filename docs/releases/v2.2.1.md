# Birak v2.2.1

A security toolchain patch on top of [v2.2.0](v2.2.0.md) (first Docker Hub image
of the v2.2 line).

## Changes

- Build and Docker image updated to **Go 1.26.11** (fixes `GO-2026-6859` in
  `net/http` `MaxBytesReader`).
- Updated `golang.org/x/crypto` to `v0.59.0` (fixes `GO-2026-5932`),
  `golang.org/x/sys` to `v0.50.0`, and `golang.org/x/text` to `v0.44.0`.

## Upgrade

Same protocol 4 and schema as v2.2.0; see [v2.2.0](v2.2.0.md) for the full
hardening and performance changelog.

## Validation

Verified with `govulncheck v1.9.0` on Go 1.26.11 (source and release binary: 0
vulnerabilities), `go vet`, and the CI Linux race, Windows build, and Docker
acceptance workflows.

## Images

Images are published for `linux/amd64` and `linux/arm64`:

```sh
docker pull solkin/birak:2.2.1
```

Version aliases: `2.2`, `2` and `latest`.
